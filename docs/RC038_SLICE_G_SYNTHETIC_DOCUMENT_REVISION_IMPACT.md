# RC-038 Slice G — fictional document-revision impact gate (no documents)

A deterministic **read-only, nonproduction, owner-scoped** change-control packet is built from two previously reviewed synthetic source sets via \`Studio::SyntheticRequirementRevisionDiff\`. The service \`Studio::SyntheticDocumentRevisionImpact\` recalculates every comparison and review receipt, rejects mismatched source digests and production/foreign owner, then proposes manual review questions for changed, newly retained, or no longer retained claims. An unchanged claim produces no change request, but absence of observed changes is not verification of approved scope.

Change rows have ephemeral coordinate IDs, classification and prior/current trace references; **no original text, values, source content hashes or filenames** are returned or stored. An absent or moved coordinate is not a deletion instruction. A deterministic report ID is a presentation identifier, not a token, approval or permission grant. Incomplete triage, ambiguous/unknown claims and partial source coverage give no change packet.

If there are changes, the existing \`Studio::DocumentGenerationPlan\` supplies the exact known artifact types and their missing prerequisites **with all evidence explicitly false**. Every affected-artifact entry is only a conservative *manual assessment candidate*, not an assertion of actual impact or generated document. All artifact generation gates remain blocked, even after owner triage. No production APIs, HTTP routes, migrations, persisted artifacts/revisions, exports, external AI calls or paid resources.

**Acceptance:** run \`bin/rails test test/services/studio/synthetic_document_revision_impact_test.rb\` with dedicated localhost \`ruby_calendar_test\`, then run full Rails suite, plus exact-HEAD GitHub CI/Security. Live user documents, confirmed recipient identities, encryption, trusted malware inspection, tested backup/restore, permissioned client review and explicit release approval remain blocking. The scope of RC-039 Project Hub and RC-040 Document Factory is unchanged.
